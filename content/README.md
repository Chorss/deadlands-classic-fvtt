# Deadlands Classic — Content Packs

Optional compendium content for the [Deadlands Classic — Community Edition](https://github.com/Chorss/deadlands-classic-fvtt)
game system for Foundry VTT.

## What this is

The game system ships the **engine** — dice, chips, wounds, card initiative, arcane
backgrounds — and one compendium of plain playing cards. It deliberately ships **no
rulebook-derived content**.

This module is where that content lives:

| Compendium | Contents |
|---|---|
| Edges | 31 Edges (`dlc` p.63-71) |
| Hindrances | 58 Hindrances (`dlc` p.52-62) |
| Hexes | Sample Huckster hexes (`dlc` p.162-163) |
| Hit Location Table | 1d20 hit-location RollTable (`dlc` p.138) |
| Archetype Examples | One example actor per archetype |

Entries carry names and mechanical values (levels, target numbers, card hands) with
short descriptions written in our own words. They are a mechanical index, not a
reproduction of the rulebook — you still need the book to play.

## Why it is separate

The Foundry package registry lists community systems on the basis that they carry
only content the author is entitled to distribute. Deadlands has no SRD and no OGL,
and Pinnacle Entertainment Group's Fan License explicitly excludes the Deadlands
setting. Keeping every rulebook-derived entry out of the registry-listed system —
and out of its distribution archive entirely — is the honest reading of that.

This module is therefore **not submitted to the package registry**. It is installed
deliberately, by manifest URL, by someone who owns the book.

## Installation

Foundry VTT → **Add-on Modules** → **Install Module** → paste into **Manifest URL**:

```
https://github.com/Chorss/deadlands-classic-fvtt/releases/latest/download/module.json
```

Requires the `deadlands-classic` system, version 0.4.1 or newer. Enable the module in
your world, then find the compendiums under the **Compendium Packs** sidebar tab.
